# Functional domains and psychopathological dimensions in first-episode psychosis: a two-year longitudinal panel-GVAR network analysis

Analysis code for a prospective two-year cohort study of first-episode psychosis
(FEP) patients enrolled in the **Parma Early Psychosis (Pr-EP)** programme,
assessed at three waves (T0 baseline, T1 = 12 months, T2 = 24 months). The study
uses a panel graphical vector autoregressive (**panel-GVAR**) model to examine
the temporal, contemporaneous, and between-subjects relationships between
psychopathological dimensions (PANSS five-factor scores) and functioning (HoNOS
items) in early psychosis.

## Nodes (9)

Five PANSS five-factor scores (van der Gaag et al.) and four HoNOS items,
estimated across three waves (27 variables total):

| Node | Content |
|------|---------|
| Positive | P1, P3, P5, P6, G9 |
| Negative | N1, N2, N3, N4, N6, G7 |
| Disorganization | P2, N5, N7, G11 |
| Excitement | P4, P7, G8, G14 |
| Emotional | G1, G2, G3, G4, G6 |
| HoNOS9 | Problems with relationships (social/interpersonal) |
| HoNOS10 | Problems with activities of daily living |
| HoNOS11 | Problems with living conditions |
| HoNOS12 | Problems with occupation and activities |

## How to run

Run the scripts in order from the repository root (paths are relative):

```r
source("scripts/00_setup.R")                    # or start at 01, which sources 00
source("scripts/01_preprocessing_covariates.R") # writes data/residuals.csv
source("scripts/02_panel_gvar_network.R")
source("scripts/03_bootstrap.R")
source("scripts/04_community_spinglass.R")
```

Scripts 02–04 each read `data/residuals.csv` and are runnable independently once
step 01 has been executed.

## Method summary

- **Preprocessing:** each node at each wave is regressed on 11 covariates (sex,
  age, ethnicity, antipsychotic, antidepressant, mood stabiliser, benzodiazepine,
  baseline DSM-5 diagnosis, T1 CBT, T1 family psychoeducation, T1 CMREC);
  standardised residuals are extracted and z-standardised (mean 0, SD 1).
- **Model:** panel-GVAR via `psychonetrics::dlvm1` (`estimator = "FIML"`,
  `within_latent = "ggm"`, `between_latent = "chol"`); a saturated model is
  fitted then pruned to a sparse model.
- **Networks:** temporal = `getmatrix(model, "beta")` (unstandardised lag-1
  regression coefficients); contemporaneous = `"omega_zeta_within"`;
  between-subjects = `"omega_zeta_between"`.
- **Centrality:** temporal in-strength (`colSums(abs(beta))`) and out-strength
  (`rowSums(abs(beta))`).
- **Bootstrap:** 1000 iterations, 75% subsample without replacement, dlvm1
  re-estimated; per-edge mean, SE and 95% CI; edges whose CI crosses zero set to 0.
- **Community analysis:** directed temporal matrix collapsed to an undirected
  weighted graph; Spinglass (`igraph::cluster_spinglass`, `implementation = "neg"`,
  `spins = 6`) per connected component over 1000 seeds; node × node co-occurrence
  matrix ordered by hierarchical clustering and shown as a heatmap.

> **Note on pruning threshold.** `02_panel_gvar_network.R` uses
> `prune(alpha = 0.5, adjust = "fdr")` while `04_community_spinglass.R` uses
> `prune(alpha = 0.05, recursive = TRUE)`, matching the original analysis
> notebook. If a single pruning rule is preferred, reconcile the two before
> final reporting.

## Data availability

Patient-level clinical data are **not** shared in this repository for privacy
reasons. `data/` is excluded via `.gitignore`. To reproduce the analysis, place
`FEP-PrEP-Roma.sav` in `data/` and run the pipeline; data may be available from
the authors on reasonable request, subject to ethical approval.
